**ShabbirDev** is a personal portfolio website developed to showcase my journey as a **Full Stack Web Developer**.

## ⚙️ Installation

Follow these steps to run the project locally.

### 1. Clone the repository

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
```

### 2. Open the project directory

```bash
cd ShabbirDev
```

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

### 5. Open the local development URL

Vite will provide a local URL in the terminal, usually similar to:

```text
http://localhost:5173
```
